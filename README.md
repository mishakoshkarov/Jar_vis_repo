# Джар_Вис

Голосовой ассистент на сцене «Центра управления». Его показывают на эфирах и встречах как личного ИИ ассистента. Чёрный терминал этого не показывает.

Джарвис бывает в двух обликах:

| Версия | Файл | Облик |
|---|---|---|
| **v4 · сфера** | `scene-v4-sfera.html` | сфера из частиц |
| **v5 · мозг** | `scene-v5-mozg.html` | мозг из частиц: извилины, ядро, пульс в такт голосу |

Обе сцены устроены одинаково: Джарвис слева, справа HUD с панелями отделов, лентой процесса и
вердиктами, внизу ход аудита. Демо-сценарий аудита карточки крутится сам. Цифры в нём
иллюстративные.

## Запуск

Нужны Node.js 18+ и Google Chrome (распознавание речи работает через Web Speech API Chrome).

```bash
npm install
cp .env.example .env      # вписать ANTHROPIC_API_KEY
npm start                 # → http://localhost:8321
```

| Адрес | Что открывается |
|---|---|
| `http://localhost:8321/` | выбор версии |
| `/v4` или `/sfera` | сфера |
| `/v5` или `/mozg` | мозг |
| `/scene` | версия по умолчанию (`JARVIS_DEFAULT_SCENE`, по умолчанию v5) |
| `/v4?demo`, `/v5?demo` | состояния Джарвиса сменяются сами, микрофон не нужен |

Если только посмотреть на фигуру, сервер не нужен: откройте HTML-файл в браузере и
добавьте `?demo` к адресу.

## Как разговаривать

1. Нажмите **V**: браузер разрешит микрофон и звук только после жеста пользователя.
2. Скажите «**Джарвис, …**» и сразу вопрос, или «Джарвис» и вопрос после паузы.
3. Джарвис думает (`/ask` → Claude API) и отвечает голосом (`/say`).

Голос, по убыванию качества:
1. **Yandex SpeechKit**, если в `.env` заданы `YANDEX_API_KEY` и `YANDEX_FOLDER_ID` (macOS, звук через `afplay`).
2. **Системный `say`** macOS (голос Milena).
3. **Голос браузера**: сцена переключается на него сама, если сервер не может говорить.

## Клавиши сцены

`V` — Джарвис вкл/выкл · `H` — панели · `F` — штат · `E` — этапы · `R` — рестарт демо ·
`1–5` — скорость · `пробел` / `→` — вердикты.

## Пульт с телефона

Чтобы управлять слушанием с телефона, запустите сервер с `JARVIS_BIND_HOST=0.0.0.0` и открывайте с телефона
`http://<ip-ноутбука>:8321/mic/remote?on=1` (включить) или `?on=0` (выключить). На ноутбуке
перед этим один раз нажмите V.

⚠️ `0.0.0.0` открывает сервер всей локальной сети, а `/ask` тратит ваш ключ Claude API. Включайте только в доверенной сети.

## Настройки (`.env`)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | ключ Claude API (обязателен для диалога) |
| `JARVIS_MODEL` | `claude-opus-5-5` | модель |
| `JARVIS_EFFORT` | `low` | глубина размышления: `low` даёт быстрый голосовой ответ |
| `JARVIS_SYSTEM` | встроенная персона | свой системный промт |
| `JARVIS_DEFAULT_SCENE` | `v5` | что отдавать по `/scene` |
| `JARVIS_BIND_HOST` | `127.0.0.1` | `0.0.0.0` открывает сервер для пульта в локальной сети |
| `PORT` | `8321` | порт |
| `YANDEX_API_KEY`, `YANDEX_FOLDER_ID` | — | голос Yandex SpeechKit |
| `YANDEX_VOICE`, `YANDEX_ROLE` | `zhanar_ru`, `friendly` | голос и амплуа |

Если модель отклонит запрос по правилам безопасности, сервер сам повторит его на запасной модели
(`fallbacks: "default"`).

## Чем эта версия отличается от рабочей

Это публичная сборка. В рабочем Джарвисе есть инструменты: запуск аудитов, доступ к файлам,
почте, календарю и базе магазина. Здесь их нет, Джарвис только разговаривает.
Ключи хранятся в `.env`, а `.env` в репозиторий не попадает.

## API сервера

| Метод | Путь | Что делает |
|---|---|---|
| `POST` | `/ask` | `{messages:[{role,content}]}` → `{reply}` |
| `POST` | `/say` | `{text}` → озвучить на сервере, `{ok}` |
| `POST` | `/mic/claim`, `/mic/release` | эстафета микрофона: слушает только одна вкладка |
| `GET` | `/mic/remote?on=1\|0`, `/mic/remote/state` | пульт |
| `GET` | `/announcements` | очередь голосовых докладов (здесь всегда пустая) |
| `GET` | `/health` | модель и состояние голоса |
